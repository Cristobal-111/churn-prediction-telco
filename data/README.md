# Datos

1. Ingresa a https://www.kaggle.com/datasets/blastchar/telco-customer-churn
2. Haz clic en **Download** (requiere cuenta gratuita de Kaggle).
3. Descomprime y copia `WA_Fn-UseC_-Telco-Customer-Churn.csv` en esta carpeta.

Si el archivo no está, el notebook lo lee automáticamente desde la fuente pública original de IBM:
https://github.com/IBM/telco-customer-churn-on-icp4d

El CSV no se versiona en el repositorio (ver `.gitignore`).
